PROTOTYPE · DECISION SUPPORT

Built to make each drop count.

This prototype uses illustrative sample profiles, local CSV records and optional NASA POWER historical weather. Dashboard rules and equations are not scientifically validated. Open-Meteo provides separate forecast estimates on request. No live sensor is connected. A separately trained soil-moisture model runs historical test cases in the research panel; it does not control the irrigation plan. The separate Python pipeline prepares experimental features; it does not run on upload.
